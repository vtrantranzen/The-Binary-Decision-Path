THE BINARY DECISION PATH
A Path to Consensus Clarity

------------------------------------------------------------

WHAT THIS IS

A manuscript documenting the Binary Path — a facilitation method
for helping a group reason its way to a clear, shared, actionable
decision. It was developed over three decades of strategy work
across several industries, and is set down here so that others may
read it, test it, use it, improve it, or refute it.

The method's premise is simple: split any problem into two main
contributors, weigh them by leverage, follow the heavier one down,
and repeat — until a room reaches consensus it can act on and own.
It is offered as a path, not a truth. There are many ways up the
mountain; this is one that has worked.

  - Foundations: what the method is, and what it deliberately leaves out

  - The Decision Compass: three plain questions that set direction
  - The Core Engine: the split, the weight, recursion, consensus
  - The Method at Work: real cases, including one where it was set aside
  - Testing the Method: how to validate it — or prove it wrong

------------------------------------------------------------

WHO IT'S FOR

Facilitators, strategists, team leaders, students of decision-making,
and anyone who has sat in a meeting that went in circles. No special
training or software is required. The method is meant to be light
enough to run with a whiteboard and a room.

------------------------------------------------------------

STATUS

This manuscript is complete: it carries the method from its
foundations through to running an actual session. It remains a
living document — the method is a version, not a final form, and
is offered for others to test, extend, or refine.

------------------------------------------------------------

AN INVITATION

This work is shared in the belief that a good method is worth handing
over — so that others may find where it leads, and where it does not.
Try it. Test it. Tell others where it held and where it failed. That
testing is not a threat to the method; it is how a path becomes a road.
